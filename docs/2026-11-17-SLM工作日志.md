## 0. 一句话总结

把大恒 GCI-770202 透射式 SLM 当二元 0/π 编码掩模，配 Basler 相机搭起单次/多掩模 lensless 成像链路；采到了合格的 PSF 与物体数据，**在 d=50 mm 几何下取得了箭头图像（分辨率 1.72 mm，约 3 个分辨元）**；TV 去卷积重建因 PSF 条件数太差未收敛，已定位为几何限制而非算法问题。

### 分辨率的硬约束（本日最重要的公式）

```
分辨率 = λ·d/p   （只由 d 决定，与 s 无关）
推导： 散斑颗粒 λs/p  ÷  放大率 m = s/d  =  λd/p
```

d=50 mm 时 **1.72 mm**；光斑边缘的软化全部来自这个数，不是算法问题。


## 4. 踩过的坑（按杀伤力排序）

| 坑 | 现象 | 教训 |
| --- | --- | --- |
| **SLM 电源没开** | Windows 正常枚举 DISPLAY2、窗口、截图全部正常，只有相机看不出调制（<0.1%）；排查了 3 小时 | 见 §5 判据，**第一件事查电源** |
| 100 µm 孔的光束只有 0.4 mm | 白纸上只看到小孔形状的圆斑，箭头图案完全不出现 | 点源不能同时当样品；物必须比光束大或自己当光源 |
| 散斑场不可迁移 | 物体差值 − PSF 差值 = 纯散斑 | PSF 与物体必须同一光路、同一照明；换光源形状散斑整体重排 |
| 分辨率 λd/p | 箭头 2 mm 在 d=50 mm 下只有 1.2 个分辨元 | 先算分辨率和物尺寸再摆光路 |
| 相机会被 Pylon Viewer 独占 | `Device is exclusively opened by another client` | 采集前关掉 Pylon Viewer |
| 相机 ROI 掉电保持 | 一直输出 400×300 中心窗口 | `cam_reset_roi.py` 复位 |
| SLM 复制模式 + 缩放 | 面板收到 1024×768 插值图 | 必须"扩展"模式 + 100% 缩放 |
| wx 不能跨线程 | slmpy 的 `updateArray` 死锁、0xC0000409 | 自写 `slm_driver.py`（wx 主线程 + 帧泵） |
| cmsub + 单张 PSF | 核被自己减成 0 → 全零输出 | 单 PSF 时不能用 cmsub |
| 差值测量被裁到 ≥0 | 一半信息丢失 | `--noclip` |
| 数据量级 1e10 配 λ=0.02 | TV 项等于 0，解退化成一堆孤立亮点 | 自动归一化（h、y 同除 std） |

## 6. 代码资产

| 文件 | 作用 |
| --- | --- |
| `slm_driver.py` | SLM 驱动（wx 主线程 + 帧泵线程，≈50 fps，apply 3.5 ms） |
| `slm_show.py` | 命令行显示（图案/`--file npy`/`--bench`/`--info`） |

| `psf_check.py` | 数据判据（饱和、边缘、质心、相关、有效秩） |
| `psf_recon.py` | TV+FISTA 重建（循环边界 FFT，自检 25.79 dB / 3.2 s） |
| `diff_runs.py` / `diff_flat.py` | 去平场、去共模 |
| `xcorr_recon.py` | 匹配滤波快速重建（秒级，用于判定数据里有没有物体） |

**`psf_recon.py` 的重建算法关键点**：用循环边界卷积（核中心对齐到 (0,0) 后补零做 `rfft2`），预合成 `S = Σ|K̂|²`、`T = Σ conj(K̂)·Ŷ`，每次迭代只需 2 次 FFT。自检 25.79 dB、3.2 秒跑完 200 次迭代（原来的线性卷积版要一小时以上）。

## 7. 下一步

优先级从高到低：

1. **把 d 从 50 mm 缩到 15 mm**（s 保持 40）
   - 分辨率升到 **0.52 mm**（提升 3.3 倍），箭头约 10 个分辨元
   - 放大率变 2.7×，箭头需缩到 **2.5 mm** 左右（否则 13.5 mm > 7.7 mm 靶面）
   - 采集：`psf_capture.py --mask binary --n 32 --seed 0 --frames 16 --bin 4 --z-mm 40 --d-mm 15`
2. **加线偏振片**：调制深度 8% → 接近 100%（×12），这是提亮与提对比度的唯一根治手段
3. **透镜直接成像验证**：f=150、d=s=300、tilt 0.10，看中心右 1.03 mm 处是否出现实像（不需要重建）
4. 重建端：改用分区标定 PSF（3×3）或设计型编码器（课题 C 线）
